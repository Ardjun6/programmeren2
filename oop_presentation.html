Wat is Object-Oriented Programming?

Object-Oriented Programming (OOP) is een programmeerparadigma gebaseerd op het concept van 'objecten'. Deze objecten bevatten zowel data (attributen) als gedrag (methoden). OOP helpt ons om complexe programma's te structureren op een manier die lijkt op hoe we over de echte wereld denken.

Kernconcepten van OOP

Encapsulatie

Data en methoden samen verpakken in één object. Dit beschermt de interne staat en zorgt voor een duidelijke interface.

Abstractie

Complexiteit verbergen en alleen essentiële details tonen. Je hoeft niet te weten hoe iets werkt om het te gebruiken.

Overerving (Inheritance)

Eigenschappen en gedrag overnemen van andere klassen. Dit bevordert hergebruik en logische hiërarchieën.

Waarom OOP Gebruiken?

🔄 Herbruikbaarheid

Code één keer schrijven en meerdere keren gebruiken. Klassen kunnen worden gebruikt om oneindig veel objecten te maken zonder code te dupliceren. Dit bespaart tijd en vermindert bugs.

🔧 Onderhoudbaarheid

Wijzigingen aanbrengen in één klasse beïnvloedt automatisch alle objecten van die klasse. Dit maakt updates eenvoudiger, voorkomt fouten, en zorgt voor consistentie.

📈 Schaalbaarheid

Nieuwe functionaliteit toevoegen door klassen uit te breiden zonder bestaande code te wijzigen. Perfect voor groeiende projecten en teamwerk.

🌍 Realistische Modellering

Code weerspiegelt de echte wereld. Een 'Auto' object heeft eigenschappen (kleur, merk) en kan dingen doen (rijden, remmen). Dit maakt code intuïtiever en gemakkelijker te begrijpen.

Concept 1: De Klasse (Class)

Wat is een Klasse?

Een klasse is een blauwdruk of sjabloon voor het maken van objecten. Het definieert welke data objecten hebben en welke acties ze kunnen uitvoeren.

Python Code Voorbeeld:
class Hond:
    def __init__(self, naam, ras):
        self.naam = naam
        self.ras = ras
    
    def blaf(self):
        print('Waf waf!')
Echte Wereld Analogie

Denk aan een bouwtekening van een huis. De tekening (klasse) beschrijft hoe elk huis eruit moet zien: aantal kamers, deuren, ramen. Je kunt deze tekening gebruiken om meerdere huizen te bouwen. Elk huis (object) volgt dezelfde blauwdruk maar kan unieke kenmerken hebben zoals kleur of adres.

🔑 Belangrijke Punten:

  • Een klasse is niet het object zelf, maar de instructies om objecten te maken
  • Je kunt oneindig veel objecten maken van één klasse
  • Elke klasse begint met het sleutelwoord class gevolgd door de naam
  • Klassennamen gebruiken meestal CamelCase (bijvoorbeeld: BankRekening, AutomobielFabriek)

Concept 2: Het Object

Wat is een Object?

Een object is een concrete instantie van een klasse. Het is het daadwerkelijke 'ding' dat bestaat in je programma met:

  • Specifieke waarden voor attributen
  • Het vermogen om methoden uit te voeren
Objecten Maken en Gebruiken:
# Objecten maken van de Hond klasse
hond1 = Hond('Max', 'Golden Retriever')
hond2 = Hond('Bella', 'Labrador')
hond3 = Hond('Rex', 'Duitse Herder')

# Objecten gebruiken
print(hond1.naam)  # Output: Max
hond2.blaf()      # Output: Waf waf!

Visuele Voorstelling van Objecten

hond1
naam: 'Max'
ras: 'Golden Retriever'
hond2
naam: 'Bella'
ras: 'Labrador'
hond3
naam: 'Rex'
ras: 'Duitse Herder'
Belangrijk Inzicht: Alle drie objecten komen van dezelfde Hond klasse, maar elk heeft unieke waarden voor naam en ras. Ze zijn allemaal honden, maar verschillende exemplaren met eigen karakteristieken.

Concept 3: Attributen (Data)

Wat zijn Attributen?

Attributen zijn de eigenschappen of kenmerken van een object. Ze slaan informatie op die het object beschrijft. In Python worden attributen gedefinieerd in de __init__ methode (de constructor).

Gedetailleerd Voorbeeld:
class Student:
    def __init__(self, naam, leeftijd, studierichting):
        self.naam = naam
        self.leeftijd = leeftijd
        self.studierichting = studierichting
        self.cijfers = []  # Leeg bij aanmaken

# Student object maken
student1 = Student('Emma', 20, 'AI')

# Attributen gebruiken
print(student1.naam)  # Output: Emma
print(student1.leeftijd)  # Output: 20

Uitleg van Attributen:

  • self.naam - Slaat de naam van de student op (string)
  • self.leeftijd - Slaat de leeftijd op (getal/integer)
  • self.studierichting - Slaat de gekozen studierichting op (string)
  • self.cijfers - Lijst om alle behaalde cijfers bij te houden (list)

🔑 Belangrijke Regel:

  • Gebruik altijd self voor attributen zodat ze bij het object horen en niet vergeten worden na de __init__ methode
  • Attributen zonder self zijn lokale variabelen die verdwijnen na de functie
  • Je kunt attributen later nog toevoegen of wijzigen via methoden
  • Gebruik duidelijke, beschrijvende namen voor je attributen

Concept 4: Methoden (Gedrag)

Wat zijn Methoden?

Methoden zijn functies die bij een object horen. Ze definiëren wat een object kan doen - de acties of het gedrag. Methoden kunnen attributen lezen én wijzigen, en kunnen ook resultaten teruggeven.

Uitgebreid Voorbeeld met BankRekening:
class BankRekening:
    def __init__(self, houder, saldo=0):
        self.houder = houder
        self.saldo = saldo
    
    def storten(self, bedrag):
        """Voegt geld toe aan het saldo"""
        self.saldo += bedrag
        return f'Gestort: €{bedrag}'
    
    def opnemen(self, bedrag):
        """Haalt geld af van het saldo"""
        if self.saldo >= bedrag:
            self.saldo -= bedrag
            return f'Opgenomen: €{bedrag}'
        return 'Onvoldoende saldo'
    
    def toon_saldo(self):
        """Toont het huidige saldo"""
        return f'Saldo van {self.houder}: €{self.saldo}'

# Gebruik van methoden
rekening = BankRekening('Lisa', 100)
rekening.storten(50)    # Saldo wordt €150
rekening.opnemen(30)   # Saldo wordt €120
print(rekening.toon_saldo())  # Output: Saldo van Lisa: €120

Methoden Uitgelegd:

  • storten(bedrag) - Voegt geld toe aan self.saldo. Gebruikt self om het attribuut te wijzigen.
  • opnemen(bedrag) - Haalt geld af van self.saldo. Controleert eerst of er genoeg saldo is (validatie).
  • toon_saldo() - Leest self.saldo en self.houder om informatie te tonen. Wijzigt niets.
⚡ Krachtig Concept: Methoden kunnen attributen lezen én wijzigen, waardoor objecten hun eigen staat kunnen beheren. Dit heet "encapsulatie" - de logica en data zijn samen verpakt in het object.

Belangrijke Punten over Methoden:

  • Eerste parameter is altijd self (verwijst naar het object zelf)
  • Methoden kunnen parameters accepteren (zoals bedrag in het voorbeeld)
  • Methoden kunnen waarden teruggeven met return
  • Gebruik docstrings (""") om uit te leggen wat een methode doet
  • Methoden kunnen andere methoden binnen dezelfde klasse aanroepen

De Constructor (__init__)

Wat is een Constructor?

De constructor (__init__) is een speciale methode die automatisch wordt uitgevoerd wanneer je een nieuw object maakt. Het initialiseert de attributen met startwaarden.

Hoe de Constructor Werkt:

1

Je roept klasse aan

hond = Hond('Max')

→
2

__init__ uitgevoerd

Attributen worden gezet

→
3

Object is klaar!

Je kunt het gebruiken

Gedetailleerd Constructor Voorbeeld:
class Auto:
    def __init__(self, merk, kleur, jaar):
        """Constructor: initialiseert een nieuwe auto"""
        self.merk = merk
        self.kleur = kleur
        self.jaar = jaar
        self.kilometer_stand = 0  # Standaardwaarde
        self.motor_aan = False
        
        # Dit wordt uitgevoerd bij maken van object
        print(f'Nieuwe {merk} aangemaakt!')

# Object maken - __init__ wordt automatisch aangeroepen
mijn_auto = Auto('Toyota', 'Blauw', 2020)
# Output: Nieuwe Toyota aangemaakt!

print(mijn_auto.merk)  # Output: Toyota
print(mijn_auto.kilometer_stand)  # Output: 0

Belangrijke Details over Constructors:

  • De eerste parameter is altijd self (verwijst naar het object dat wordt aangemaakt)
  • Je kunt standaardwaarden instellen voor parameters (zoals saldo=0)
  • __init__ wordt automatisch aangeroepen - jij roept het niet expliciet aan
  • Attributen die je in __init__ maakt zijn beschikbaar in alle methoden van de klasse
  • Je kunt validatie toevoegen in __init__ om te controleren of de waarden correct zijn
  • Code in __init__ wordt maar één keer uitgevoerd: bij het aanmaken van het object

Praktisch Voorbeeld: Volledige Klasse

Hier is een complete, praktische klasse die alle concepten combineert: klasse, attributen, methoden, en de constructor.

Volledige TakenLijst Klasse:
class TakenLijst:
    """Klasse om taken te beheren voor een gebruiker"""
    
    def __init__(self, eigenaar):
        """Constructor: maakt nieuwe takenlijst aan"""
        self.eigenaar = eigenaar
        self.taken = []
        print(f'Takenlijst aangemaakt voor {eigenaar}')
    
    def voeg_taak_toe(self, taak):
        """Voegt een taak toe aan de lijst"""
        self.taken.append(taak)
        print(f'✓ Taak toegevoegd: {taak}')
    
    def verwijder_taak(self, taak):
        """Verwijdert een taak van de lijst"""
        if taak in self.taken:
            self.taken.remove(taak)
            print(f'✗ Taak verwijderd: {taak}')
        else:
            print(f'Taak niet gevonden: {taak}')
    
    def aantal_taken(self):
        """Geeft het aantal taken terug"""
        return len(self.taken)
    
    def toon_taken(self):
        """Toont alle taken in een genummerde lijst"""
        print(f'\n📋 Taken van {self.eigenaar}:')
        if not self.taken:
            print('  (Geen taken)')
        else:
            for idx, taak in enumerate(self.taken, 1):
                print(f'  {idx}. {taak}')
    
    def is_leeg(self):
        """Controleert of de lijst leeg is"""
        return len(self.taken) == 0
Gebruik van de TakenLijst Klasse:
# Object maken
mijn_lijst = TakenLijst('Sophie')
# Output: Takenlijst aangemaakt voor Sophie

# Taken toevoegen
mijn_lijst.voeg_taak_toe('Python leren')
# Output: ✓ Taak toegevoegd: Python leren

mijn_lijst.voeg_taak_toe('OOP oefenen')
# Output: ✓ Taak toegevoegd: OOP oefenen

mijn_lijst.voeg_taak_toe('Project maken')
# Output: ✓ Taak toegevoegd: Project maken

# Aantal taken checken
print(f'Aantal taken: {mijn_lijst.aantal_taken()}')
# Output: Aantal taken: 3

# Alle taken tonen
mijn_lijst.toon_taken()
# Output:
# 📋 Taken van Sophie:
#   1. Python leren
#   2. OOP oefenen
#   3. Project maken

# Taak verwijderen
mijn_lijst.verwijder_taak('OOP oefenen')
# Output: ✗ Taak verwijderd: OOP oefenen

# Controleren of lijst leeg is
print(f'Is leeg? {mijn_lijst.is_leeg()}')
# Output: Is leeg? False

Wat Gebeurt Hier?

1️⃣ Constructor Initializeert

De __init__ methode maakt het object aan met eigenaar = 'Sophie' en een lege taken lijst. Het object is nu klaar om te gebruiken.

2️⃣ Methoden Wijzigen Staat

De voeg_taak_toe() methode voegt items toe aan self.taken en geeft feedback. De lijst wordt intern bijgehouden in het object.

3️⃣ Methoden Lezen Data

toon_taken() leest self.taken en self.eigenaar om alles mooi geformatteerd te tonen. Het wijzigt niets, alleen weergeven.

📚 Opdracht 1: Boek Klasse (Basis)

Doel: Leer de basis van klassen, attributen en eenvoudige methoden.

Maak een Boek klasse met de volgende attributen:

  • titel (string) - De titel van het boek
  • auteur (string) - De schrijver van het boek

Voeg deze methoden toe:

  • toon_info() - Print alle informatie over het boek (titel, auteur, jaar, en of het gelezen is)

🛒 Opdracht 2: Winkelwagen Klasse (Gemiddeld)

Maak een Winkelwagen klasse met de volgende attributen:

  • klant_naam (string) - Naam van de klant

Implementeer deze methoden:

  • voeg_product_toe(naam, prijs) - Voegt een product (als dictionary) toe aan de lijst

Extra uitdaging: Voeg een apply_discount(percentage) methode toe die een korting toepast op alle producten.

🎮 Opdracht 3: Speler Klasse voor Game (Uitdagend)

Doel: Maak een complexe klasse met interacterende methoden en state management.

Maak een Speler klasse voor een RPG game met deze attributen:

  • naam (string) - Naam van de speler
  • level (int) - Begint op 1
  • health (int) - Begint op 100
  • max_health (int) - Maximum health (100)
  • experience (int) - Begint op 0
  • inventory (lijst) - Lege lijst bij start

Implementeer deze methoden:

  • neem_schade(schade) - Vermindert health, check of speler nog leeft (health > 0). Print een bericht.
  • genees(hoeveelheid) - Verhoogt health, maar niet boven max_health. Print hoeveel gehealed.
  • krijg_exp(exp) - Voegt experience toe. Bij 100 exp: level omhoog, exp reset naar 0, health = max_health. Print level up!
  • voeg_item_toe(item) - Voegt item toe aan inventory
  • gebruik_item(item) - Verwijdert item uit inventory als het bestaat, anders print "Item niet in inventory"
  • toon_status() - Print alle stats (naam, level, health, exp, inventory)
  • is_levend() - Returnt True als health > 0

Extra uitdaging:

  • Voeg een aanval_kracht attribuut toe dat stijgt met level
  • Maak een val_aan(tegenstander) methode die schade toebrengt aan een andere Speler instance
  • Implementeer een save_game() methode die alle data opslaat in een dictionary

Test scenario:

held = Speler("Aragorn")
held.toon_status()

# Combat scenario
held.neem_schade(30)
held.genees(20)
held.voeg_item_toe("Zwaard")
held.voeg_item_toe("Schild")

# Ervaring opdoen
held.krijg_exp(50)
held.krijg_exp(60)  # Zou level up moeten triggeren

held.toon_status()

💡 Tips voor de Opdrachten:

  • Begin met het schrijven van de constructor (__init__) - definieer alle attributen
  • Test elke methode apart voordat je verdergaat naar de volgende
  • Gebruik print() statements om te debuggen en te zien wat er gebeurt
  • Vergeet niet self te gebruiken voor alle attributen en bij het aanroepen van andere methoden
  • Maak meerdere objecten om te testen of alles werkt (bijvoorbeeld 3 verschillende boeken)
  • Vraag jezelf af: "Wat moet er gebeuren als...?" en test edge cases
